# 讨论室 vs OpenClaw 群聊：普通用户怎么选

先把两个东西说人话：

- **OpenClaw 群聊**：把 AI 助手装进 QQ、Discord、飞书这些聊天软件里。你可以拉几个机器人进同一个群，它们看到消息就在群里接话，你能直接看到 reply。
- **多智能体讨论室**：OpenChamber 里的一个页面。给几个 AI 各自开一个独立会话，放进同一个「房间」，像一场有纪要、有未读清单的会议。

**一句话结论**：想快速看几个 AI 对同一句话的反应，用群聊；想认真开一场会、事后查得到谁读了谁没回、问题有正式答案、随时能喊停，用讨论室。

## 六个场景，看看哪里不一样

### 1. 你丢一个议题进去

**群聊里**：配置好的几个机器人几乎同时开始跑，答案一条条刷到群里。快，但也容易几个人抢着说同一件事。

**讨论室里**：所有人都记下「你有一条新消息」，但不马上叫醒。各自手头的活干完，才收到一句「你有 3 条未读」。想发言的人自己去读全文，其他人继续做自己的事。房间是安静的。

### 2. 你 @ 某个人催他

**群聊里**：@ 主要决定「这条消息接不接」，通常不会变成插队。Discord 还有防刷屏：两个机器人 60 秒内互答超过 20 条，会被一起静音一会儿。

**讨论室里**：被点名的人走「紧急提醒」，插到他下一次能听话的缝隙里；没被点名的人还是按普通顺序等。你可以只催一个人，不影响其他人。

### 3. 有人没回，你们接着聊

**群聊里**：一轮就是一轮，聊完散场，没有「他还没读」这回事。Gateway 重启后，这轮讨论的进度也没了。

**讨论室里**：没读就是没读。这个人这轮结束还会再被提醒一次，直到他读完，或者你按下暂停。沉默不等于同意。你一按暂停，全房间都不再自动叫人，但聊天记录照常写，回来点继续还能接着聊。

### 4. 你问了一个正经问题

**群聊里**：没有「正式问题」这个概念。谁问的都是一条普通消息，谁都能顺手答一句，答完就沉下去了。

**讨论室里**：问题会变成群里一张卡片，明确标着「待回答」。提问题的 AI 可以先去干别的；只有真人能正式作答。答完，提问的人会被叫回来，并直接拿到答案的位置。重复的问题可以撤回、标记成已回答过。

### 5. 有人说了很长一段

**群聊里**：整段直接发到平台，长了容易刷屏，后来的人得往上翻。

**讨论室里**：每条发言短一些（约 200 字宽）；长论证写到房间临时文件，群里只贴一个路径。想看细节点开文件，不想看就跳过。

### 6. 谁在说话

**群聊里**：靠平台上的机器人账号区分。如果一个机器人带好几个 AI，群里看到的作者都是同一个机器人，得靠名字文字去猜。

**讨论室里**：每个成员有固定身份和名字，发言带上是谁说的；AI 不能自己谎报身份。改名也不会改掉历史记录里的归属。

## 一眼看懂

| 你在意什么 | OpenClaw 群聊 | 讨论室 |
| --- | --- | --- |
| 第一反应 | 几条消息同时冒出来 | 安静记下，等各自空闲再看 |
| 催某个人 | @ 决定接不接，不一定插队 | 点名走紧急提醒，只叫这一个 |
| 有人没回 | 一轮结束就散 | 持续提醒到读完或你喊停 |
| 问题怎么算答 | 又一条普通消息 | 待答卡片，真人正式回答 |
| 一键停住 | 没有全房间开关 | 暂停后不再自动叫人 |
| 看得见的进度 | 平台聊天记录 | 未读清单、已读详情、唤醒次数 |

## 什么时候用哪个

**用群聊，如果你：**

- 就在 QQ / Discord / 飞书里办公，不想再开一个页面；
- 想马上看到几个模型对同一件事的不同意见；
- 需要机器人做定时、后台任务、跨平台通知这些事。

**用讨论室，如果你：**

- 想认真辩一轮，而不是看几条各自独立的回答；
- 在意谁读了、谁没回、谁被催过、谁改了结论；
- 想让问题有正式答案，讨论有据可查；
- 需要随时暂停、控制唤醒次数，避免一堆机器人互相刷屏。

## 也要说清楚边界

- OpenClaw 的强项是「群聊本身」：平台自带历史、@、手机通知，机器人任务、定时和后台执行都很成熟。讨论室不做这些。
- 个人微信目前**没有群聊**：官方微信插件只支持私信和媒体。想在群里讨论，得用 QQ、Discord、飞书这些渠道。
- 讨论室目前是**本机版本**：几个 AI 共用同一个项目工作区，同时改同一个文件会冲突；长内容建议写进房间临时目录。还不支持跨机器房间。

## 怎么试

在 OpenChamber 侧栏打开「页面 → 多智能体讨论室」→ 新建房间 → 选好成员和模型 → 等成员会话都就绪 → 发第一条议题。关掉页面不会中断提醒，回来还在。

更细的机制对照见 [调研文档](research.md)。
